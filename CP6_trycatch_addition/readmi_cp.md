Вариант 1. Парсер списка чисел
Метод int SumValidNumbers(List<string> values) суммирует корректные числа из списка строк.
Для каждого значения пытайтесь выполнить int.Parse.
catch (FormatException ex) when (string.IsNullOrWhiteSpace(value)) — пустые строки пропускайте без логирования (это ожидаемый, частый случай).
catch (FormatException ex) (без when) — для остальных ошибок формата выводите предупреждение и продолжайте обработку следующих значений.
catch (OverflowException ex) — это считается критической, неожидаемой ситуацией для метода: выведите сообщение и выполните throw;, чтобы передать её вызывающему коду, не теряя стек вызовов.
Используйте finally (на каждой итерации или один раз для всего метода — на ваш выбор) для логирования количества обработанных элементов.

Проверочные ключи

На входе ["10", "", "abc", "20"]:

"10" — складывается, сумма += 10
"" — пропускается без предупреждения (фильтр when)
"abc" — предупреждение в лог, обработка продолжается
"20" — складывается, сумма += 20
итог — сумма 30, метод не выбросил исключение

При значении "99999999999" (переполнение int) метод выполняет throw; и передаёт
OverflowException наверх, а не проглатывает его. finally при этом всё равно отрабатывает.
